# Rust Exercises

![Ferrous Systems logo](https://avatars.githubusercontent.com/u/41755915?s=200&v=4)

This repository contains my attempt at the Rust exercises from Ferrous Systems. I’m using it to practice Rust and track my progress through the exercises.

In FizzBuzz, I check whether a number is divisible by 15 to identify numbers divisible by both 3 and 5. This lets me handle the FizzBuzz case with `number % 15 == 0` instead of checking `number % 3 == 0 && number % 5 == 0` separately.
